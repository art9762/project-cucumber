# Project cucumber

Платформа для отслеживания новых идей и проектов в сфере ИИ и IT: собирает данные
из публичных источников в единую базу и строит поверх неё анализ.

Проект состоит из двух частей с чётким разделением: **сбор** данных и **анализ**
поверх собранной базы.

## Структура

| Часть | Что это | Статус |
|-------|---------|--------|
| [`search engine/`](search%20engine/) | Ядро сбора (`find-engine`): парсит GitHub, Reddit, Hacker News, arXiv в единую базу PostgreSQL. HTTP API + cron, инкрементальный добор и дедуп. | v1 реализован |
| [`analysis/`](analysis/) | Анализ поверх собранной базы: классификация, скоринг/тирлист, эмбеддинги, analysis API. Читает базу движка read-only, складывает результаты в свои таблицы. | Фаза 0 (каркас) готова |
| `test ui/` | Прежний черновик UI; будет заменён модулем `ui/` (Фаза 5). | задел |

План модуля анализа и разбивка по фазам: [`docs/analysis-plan.md`](docs/analysis-plan.md),
[`docs/KICKOFF.md`](docs/KICKOFF.md).

## Архитектура в двух словах

```
источники (GitHub, Reddit, HN, arXiv)
        │
        ▼
  search engine  ──►  PostgreSQL (items + raw_records + jobs)
                            │  read-only
                            ▼
                        analysis  (классификация, скоринг, эмбеддинги, API)
                            │
                            ▼
                          ui  (панель управления, умный поиск)
```

Ядро **только собирает** данные. Анализ, поиск конкурентов и UI живут отдельно и
читают готовую базу — это позволяет развивать сбор и анализ независимо.

## Планы

- Анализ собранной базы: дерево категорий, скоринг/тирлист, поиск конкурентов (`analysis/`).
- Семантический поиск / эмбеддинги (pgvector — схема ядра к этому готова).
- Панель управления и умный поиск (`ui/`, Фаза 5).
- HTML-парсинг произвольных форумов (v2 источников).
